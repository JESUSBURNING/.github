The JESUSBURNING House of 589's is a safe haven: come as you are, help the unseen, and keep the lamp warm.

## What lives here

This `.github` repository holds the organization's shared community files
and its public GitHub profile.

It is a small front door to the House, not an application to install.

## Find your way

- [Organization profile](profile/README.md): the welcome, vision, and House links.
- Shared community files belong here as they are added.
- Individual projects keep their own code and project-specific documentation.

## A little care

Keep changes welcoming, clear, and free of personal information.
Leave each doorway easier for the next visitor to understand.
